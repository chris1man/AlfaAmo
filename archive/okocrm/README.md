# Архив: интеграция okoCRM

Интеграция okoCRM с Альфа-Банком больше не используется и перенесена сюда без изменений логики. Рабочий код (amoCRM) в корне репозитория от неё не зависит.

- Значения токенов в `oko_config.py` убраны: теперь читаются из переменных окружения (`OKOCRM_ACCESS_TOKEN`, `SBP2_PAYMENT_TOKEN`, `SBP2_CALLBACK_TOKEN`, `SBP2_RETURN_URL`, `SBP2_CALLBACK_URL`). Прежние значения остались в истории git, поэтому их нужно перевыпустить.
- Чтобы вернуть интеграцию, скопируйте файлы обратно в корень (импорты рассчитаны на запуск из корня).
- `multi_system_handler.py` был нерабочим (Flask-приложения регистрировались как blueprint), в архиве сохранён как есть.
- Описание: `OKOCRM_README.md`.
